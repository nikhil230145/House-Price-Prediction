# House Price Prediction 🏠

A Machine Learning project that predicts house prices using features like location, size, and number of rooms. Built using Python and Scikit-learn for accurate price prediction.

## 📊 Project Overview

This project uses machine learning algorithms to predict house prices in Bengaluru based on various features such as:
- **Location** - Property location in the city
- **House Size** - Size in square feet (sq. ft)
- **Number of Rooms** - BHK (Bedrooms, Halls, Kitchens)
- **Price** - Target variable to predict

## 🛠️ Technologies Used

- **Python 3.x** - Programming language
- **Scikit-learn** - Machine Learning algorithms
- **Pandas** - Data manipulation and analysis
- **NumPy** - Numerical computations
- **Matplotlib/Seaborn** - Data visualization

## 🔧 How It Works

1. **Data Loading** - Reads the CSV dataset
2. **Data Preprocessing** - Cleans and prepares data
3. **Model Training** - Trains ML model
4. **Prediction** - Predicts house prices
5. **Evaluation** - Measures model accuracy
